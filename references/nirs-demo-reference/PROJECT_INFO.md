# 工程标注：双 MAX30102 肌肉 NIRS 相对趋势原型

- **工程 ID**：`SEN-NIR-001`
- **分类**：传感器原型 / 近红外肌肉检测
- **状态**：固件与上位机已实现、待双模块实机验证
- **硬件**：2 x MAX30102 + XIAO ESP32-S3，双硬件 I2C
- **输出**：短距/长距红光与红外原始值、ΔO₂Hb/ΔHHb/ΔtHb/HbDiff 相对估算、低置信度参考锚定 SmO₂、置信度、CSV
- **实验教练层**：透明的 5 状态、0–100 即时负荷、恢复提示与累计 MSS；不是 Train.Red 专有评分
- **固件入口**：`firmware/dual_max30102_nirs/dual_max30102_nirs.ino`
- **上位机入口**：`host/index.html`
- **启动**：双击 `启动NIRS上位机.command`，或使用端口 8084 的本地 HTTP 服务
- **版本管理**：当前没有独立 Git 仓库
- **资料**：`传感器材料/心率/MAX30102.pdf`

用途边界：仅用于光路与相对趋势验证，不输出绝对肌氧，不可用于医疗用途。
