# 双 MAX30102 肌肉 NIRS 相对趋势原型

本工程验证一个低成本双距离近红外光学方案：一块 MAX30102 作为光源与短距离参考通道，另一块 MAX30102 关闭自身 LED，作为长距离接收通道。XIAO ESP32-S3 同时读取两块芯片，上位机显示 ΔO₂Hb、ΔHHb、ΔtHb、HbDiff 相对估算、测量置信度与光路质量，并导出 CSV。

上位机还提供独立的实验性“肌肉教练”层：用 HbDiff 去氧幅度、ΔtHb 压迫特征、短时变化斜率和会话个体范围划分 1–5 状态（恢复、轻松、中等、高强度、负荷上升），生成 0–100 即时负荷分数、恢复提示和随时间累积的实验 MSS。此模型受 Train.Red 公开的状态框架启发，但公式为本项目自行设计，未复制或声称等同于其未公开算法。

指标计算前默认经过 5 点中值去尖峰和 1 Hz 一阶低通；界面可选择 1/2/4 Hz。状态判定还使用 3 秒滞回、1.5 秒大跨度确认和 2.5 秒评分平滑。暗场与自动光路诊断继续使用原始数据；光路掉线或切换滤波后必须重新验证并记录基线。

> 这是可行性验证，不是医疗设备。四项血红蛋白指标均为相对基线的 mOD 等效估算，不是微摩尔浓度；SmO₂ 是以用户输入基线百分比锚定的低置信度实验推算，不是绝对测量，不可用于诊断或治疗。

## 1. 为什么不能把两块模块直接并联

两块 MAX30102 的固定 7 位 I2C 地址都是 `0x57`，不能直接共享一组 SDA/SCL。本工程使用 XIAO ESP32-S3 的两套硬件 I2C 控制器：

- 光源模块使用 `D4/GPIO5` 与 `D5/GPIO6`；
- 接收模块使用 `D2/GPIO3` 与 `D3/GPIO4`；
- 两块模块只共用 `3V3` 和 `GND`。

MAX30102 的 LED 脉冲与 ADC 采样由芯片内部振荡器控制，并没有外部同步触发脚。本工程用背靠背启动和可调微秒偏移尽量对齐两块芯片，因此属于实验性同步。若长距通道始终接近暗电流或会周期性消失，优先执行“重新同步”并调整相位偏移；最终产品应改为由同一 AFE 控制的外置双波长 LED 与光电二极管。

## 2. 接线

接线前拔掉 USB。参考照片中靠近 XIAO 的模块作为光源，远离 XIAO 的模块作为接收端。

| 模块 | MAX30102 引脚 | XIAO ESP32-S3 | 说明 |
| --- | --- | --- | --- |
| 光源 / 短距参考 | VIN | 3V3 | 两块都使用 3.3 V |
| 光源 / 短距参考 | GND | GND | 必须共地 |
| 光源 / 短距参考 | SDA | D4 / GPIO5 | I2C 总线 0 |
| 光源 / 短距参考 | SCL | D5 / GPIO6 | I2C 总线 0 |
| 接收 / 长距 | VIN | 3V3 | 与光源模块共电源 |
| 接收 / 长距 | GND | GND | 与光源模块共地 |
| 接收 / 长距 | SDA | D2 / GPIO3 | I2C 总线 1 |
| 接收 / 长距 | SCL | D3 / GPIO4 | I2C 总线 1 |
| 两块模块 | INT / RD / IRD | 不接 | 首版不使用 |

禁止把两块模块的 SDA 或 SCL 接在一起。XIAO GPIO 不是 5 V 耐受，本工程不使用 5 V 给模块供电。

## 3. 探头摆放

1. 两块传感器窗口朝向同一块肌肉皮肤，窗口中心间距先设为 `25–30 mm`；如果长距信号太弱，先缩短到 `10–20 mm` 验证光路，再逐步加大。
2. 使用不透光黑色泡棉包围两块模块，阻挡室内光和模块之间经过空气的直射光；不要在皮肤下方的漫反射路径上放黑色隔断。
3. 两块模块要贴平皮肤并保持相同压力。压力变化会改变局部血流和光耦合，容易被误认为肌肉氧合变化。
4. 先在前臂或股外侧做静息基线，再做 5–10 秒等长收缩，避免一开始就进行大幅运动。

## 6. 调参顺序

### 接收端几乎没有信号

1. 先把探头间距缩短到 10–15 mm；
2. 遮光并确保两个窗口贴平皮肤；
3. 运行“自动光路验证”，让软件比较暗场并扫描 `-5000 us` 到 `+5000 us`；
4. 如果自动验证中断，再点击“重新同步”检查两块模块是否仍在线；
5. 当前测试版默认 LED 寄存器为 `220`（约 44 mA 峰值）。芯片虽允许更高电流，但本面包板原型在 `255` 档出现无数据/疑似供电掉压，因此软件上限保守设为 `220`。保持探头遮光；如模块明显发热或贴肤不适，应立即降低电流或停止测试。

自动验证的通过条件是接收端 RED 和 IR 都比各自暗场至少增加 64 counts 且增加 8%，同时没有饱和。这是工程门槛，不是生理准确度证明。

### 信号饱和或温度明显上升

降低 LED 寄存器、减小贴合压力或稍微增加间距。改变电流、间距、相位或探头压力后必须重新做基线校准。

### 相对趋势漂移很大

优先检查探头移动、环境漏光、皮肤接触压力和两块芯片的相位漂移。单次实验建议先控制在 1–3 分钟，并记录动作时间点用于后处理。

## 7. 指标含义

上位机先计算长距与短距通道相对基线的光密度变化：

```text
DeltaOD = -ln(I / I0)
correctedOD = longOD - 0.5 * shortOD
oxygenation trend = 1000 * (correctedIR - correctedRED)
blood volume trend = 1000 * (correctedIR + correctedRED) / 2
```

单位 `mOD-eq` 是基于千分之一光密度的等效趋势。软件用 `ΔtHb` 和 `HbDiff` 做透明的双分量分解：`ΔO₂Hb=(ΔtHb+HbDiff)/2`、`ΔHHb=(ΔtHb-HbDiff)/2`。短距权重 `0.5` 是首版经验值，只用于降低表层接触与血流变化的影响。由于没有测量差分路径长度因子、光程、消光系数和个体组织参数，软件不会把这些趋势冒充为微摩尔浓度或绝对肌氧百分比。

## 8. 串口协议

115200 baud、JSONL、Protocol v2。采样包示例：

```json
{"type":"samples","seq":1,"sampleSeq":5,"ms":1234,"rate":100,"sourceRed":[42000],"sourceIr":[51000],"detectorRed":[8200],"detectorIr":[9900],"tempC":30.5}
```

支持命令：

- `PING`
- `STATUS`
- `SYNC`
- `RESET`
- `LIGHT:0` / `LIGHT:1`
- `LED:1..220`
- `OFFSET:-5000..5000`

`LIGHT:0` 用于自动暗场测量。固件会在 15 秒后自动恢复光源，避免浏览器意外断开后一直停留在暗场状态。

## 9. 下一步硬件判定门槛

只有同时满足以下条件，才值得继续用双 MAX30102 做结构迭代：

- 长距 RED 和 IR 在 25–30 mm 间距下稳定高于暗电流；
- 改变 LED 电流时长距通道方向一致、可重复响应；
- 静止 60 秒时基线漂移明显小于一次等长收缩引起的变化；
- 多次重新佩戴后趋势方向可重复。

如果第 1 或第 2 项无法满足，不建议继续靠软件补偿；应转为同一时钟控制的 660 nm / 850–880 nm 外置 LED、光电二极管和专用光学 AFE。
