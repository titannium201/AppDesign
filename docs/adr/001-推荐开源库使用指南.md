# ADR-001：推荐开源库在 AppDesign 中的使用方式

> 状态：已采纳  
> 日期：2026-08-08

## 背景

上一版规划列出了多个 GitHub 开源项目。本 ADR 明确它们将以何种方式进入 `AppDesign` 仓库：

1. **作为 npm/pnpm 依赖安装**：直接成为 monorepo 中某个 package 的 `dependencies` / `devDependencies`。
2. **作为代码/架构参考**：不直接依赖，而是阅读其源码、协议或示例后，在本项目中重写或适配。
3. **作为 Skill / 工具**：安装到 CodeBuddy 中，提升 Agent 编写或调试该类代码的能力。

## 1. 3D 肌肉可视化

### three.js
- **用途**：WebGL 底层渲染。
- **使用方式**：`@app/muscle-3d` 直接依赖。
- **安装**：
  ```bash
  pnpm --filter @app/muscle-3d add three
  pnpm --filter @app/muscle-3d add -D @types/three
  ```
- **本项目用法**：
  - 加载腿部肌肉 GLTF/FBX 模型。
  - 管理 `Scene`、`Camera`、`Renderer`。

### React Three Fiber (R3F)
- **用途**：在 React 中声明式写 Three.js。
- **使用方式**：`@app/muscle-3d` 与 `apps/web-3d` 依赖。
- **安装**：
  ```bash
  pnpm --filter @app/muscle-3d add @react-three/fiber
  ```
- **本项目用法**：
  - 把模型、光照、控制器封装成 React 组件。
  - 通过 props 接收 NIRS 热力数据并驱动材质颜色变化。

### React Three Drei
- **用途**：3D 常用辅助组件（OrbitControls、Environment、Gltf/useGLTF 等）。
- **安装**：
  ```bash
  pnpm --filter @app/muscle-3d add @react-three/drei
  ```
- **本项目用法**：
  - `useGLTF` 加载肌肉模型。
  - `OrbitControls` 让用户旋转、缩放腿部模型。

### React Three Post Processing
- **用途**：后处理效果（辉光、颜色校正），用于增强热力图视觉。
- **安装**：
  ```bash
  pnpm --filter @app/muscle-3d add @react-three/postprocessing
  ```
- **本项目用法**：
  - 为高热力值区域添加 Bloom 效果。

### leva
- **用途**：调试面板，开发阶段调节肌肉颜色阈值、透明度。
- **安装**：
  ```bash
  pnpm --filter @app/web-3d add -D leva
  ```
- **本项目用法**：
  - 开发环境下调节 `heatmapMin`、`heatmapMax`、`opacity` 等参数。

## 2. iOS 风格 App（跨端）

### Expo
- **用途**：React Native 快速开发、热更新、构建服务（EAS）。
- **使用方式**：`apps/mobile` 基于 Expo 初始化。
- **安装**：
  ```bash
  pnpm dlx create-expo-app apps/mobile --template blank-typescript
  ```
- **本项目用法**：
  - 统一运行 `pnpm --filter @app/mobile start`。
  - 使用 Expo Router 管理页面路由。

### React Navigation
- **用途**：页面导航（栈、标签、抽屉）。
- **安装**：
  ```bash
  pnpm --filter @app/mobile add @react-navigation/native @react-navigation/native-stack
  ```
- **本项目用法**：
  - 首页 → 训练页 → 3D 可视化页 → 个人中心 的栈导航。

### React Native Reanimated + Gesture Handler
- **用途**：流畅动画与手势（底部弹窗、滑动、图表交互）。
- **安装**：
  ```bash
  pnpm --filter @app/mobile add react-native-reanimated react-native-gesture-handler
  ```
- **本项目用法**：
  - 首页训练卡片滑动、数据面板展开动效。

### React Native UI Kitten / Tamagui / NativeWind
- **用途**：iOS 风格组件库/样式方案。
- **建议**：
  - 如追求 **开箱即用 iOS 组件**，选 **React Native UI Kitten**。
  - 如追求 **跨平台一致性 + 主题系统**，选 **Tamagui**。
  - 如团队熟悉 Tailwind，选 **NativeWind**。
- **本项目用法**：
  - 在 `packages/ui` 中封装 Button、Card、SegmentedControl 等基础组件。
  - `apps/mobile` 直接引用 `@app/ui`。

## 3. 蓝牙 BLE / 硬件接入

### react-native-ble-plx
- **用途**：React Native 与 NIRS 设备通过 BLE 通信。
- **使用方式**：`@app/nirs-sdk` 直接依赖。
- **安装**：
  ```bash
  pnpm --filter @app/nirs-sdk add react-native-ble-plx
  ```
- **本项目用法**：
  - 扫描设备 → 连接 → 订阅特征值 → 解析 NIRS 原始数据。
  - 参考 `https://github.com/titannium201/NIRSdemo` 中的 UUID 与数据格式。

### Web Bluetooth API 示例
- **用途**：Web 端调试或 H5 内嵌时蓝牙通信参考。
- **使用方式**：**参考实现**，不直接依赖。
- **本项目用法**：
  - 阅读 `WebBluetoothCG/demos` 中数据订阅模式。
  - 在 `apps/web-3d` 中实现可选 Web 蓝牙调试入口（仅 Chrome/Edge）。

## 4. 后端与数据服务

### NestJS
- **用途**：`services/api-gateway` 后端框架。
- **安装**：
  ```bash
  pnpm --filter @app/api-gateway add @nestjs/common @nestjs/core @nestjs/platform-express
  pnpm --filter @app/api-gateway add -D @nestjs/cli @nestjs/schematics @nestjs/testing
  ```
- **本项目用法**：
  - 用户模块、设备模块、训练记录模块、数据同步模块。
  - 使用 Guards、Interceptors、Pipes 统一鉴权与校验。

### Prisma
- **用途**：ORM 与数据库迁移。
- **安装**：
  ```bash
  pnpm --filter @app/api-gateway add -D prisma
  pnpm --filter @app/api-gateway add @prisma/client
  ```
- **本项目用法**：
  - 定义 `User`、`Device`、`Workout`、`MuscleData` 等模型。
  - 通过迁移脚本管理数据库结构变更。

### BullMQ
- **用途**：异步任务队列（算法计算、第三方数据同步）。
- **安装**：
  ```bash
  pnpm --filter @app/api-gateway add bullmq ioredis
  ```
- **本项目用法**：
  - 用户上传一次训练数据后，放入队列进行疲劳评估计算。

### Zod
- **用途**：运行时类型校验。
- **安装**：
  ```bash
  pnpm --filter @app/api-gateway add zod
  ```
- **本项目用法**：
  - DTO 校验、环境变量校验、API 返回类型校验。

### Supabase（可选）
- **用途**：如不想自建 PostgreSQL/Auth，可直接托管。
- **使用方式**：**可选托管服务**，不直接作为代码依赖。
- **本项目用法**：
  - 把 `api-gateway` 数据库接到 Supabase PostgreSQL。
  - 使用 Supabase Auth 替代自建登录（可选）。

- **本项目用法**：
  - 测试 3D 页面加载、热力图切换、蓝牙调试入口。

## 10. 使用原则总结

1. **优先用官方/成熟库**：three.js、Expo、NestJS、Zod 等。
2. **谨慎引入 RN 原生模块**：每引入一个原生依赖，都会增加 iOS/Android 构建复杂度。
3. **先在 `packages/*` 封装再使用**：避免业务代码直接依赖第三方库细节。
4. **保留参考仓库但不复制**：`NIRSdemo` 只作为协议参考，不在 `AppDesign` 中直接复制其代码。
5. **按需安装**：每进入一个开发阶段，再安装对应依赖，避免一次性安装过多导致冲突。
